# selection-assessment-analysis

This repository contains the analysis code for an evaluation of a 15-item hiring assessment used to select sales associates at a retail company. The analysis examined which items predicted job performance, whether using them would produce adverse impact across race and gender, and how to weight the predictors in a hiring composite.

The case study writeup is available at https://othmanjournal.com/portfolio/selection-assessment.html

Files

selection-assessment.sas — SAS syntax for the full analysis pipeline. Includes factor analysis of the 15 assessment items, reliability (Cronbach's alpha) for each factor, multiple regression predicting performance ratings and rule infractions, t-tests for race and gender differences on each predictor, adverse impact ratio calculations, and a simulation comparing equal weighting versus optimal weighting for a top-100 hiring scenario.
